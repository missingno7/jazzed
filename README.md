# Jazzed

Jazzed is a desktop level editor for the original DOS release of **Jazz Jackrabbit 1**. It edits the original game data files directly; it is not an OpenJazz project format editor.

The repository intentionally does not include copyrighted game assets. Put your local DOS game files in `game_data/` when running the editor.

## Current Status

Jazzed is a working editor prototype with a Tk/Pillow GUI. It can load JJ1 levels, render maps and tilesets, inspect and edit level-local event definitions, masks, animations, paths, bullets, object placements, metadata, and save modified level files.

OpenJazz source code is useful as a reference while developing the parser, but it is not required at runtime and is not part of the public repository.

## Project Layout

```text
jazz1_dos_level_editor.py   Compatibility launcher
jazzed_editor/
  app.py                    Command-line entrypoint
  gui.py                    Tk app shell and mixin composition
  gui_parts/                GUI mixins split by editor workflow
  raw_data.py               Compatibility facade for raw data imports
  raw/
    constants.py            JJ1 format and game constants
    codecs.py               Binary helpers: RLE, palettes, signed bytes
    event_semantics.py      Event names, categories, descriptions
    models.py               Level, tileset, sprite, path, bullet data classes
    parser.py               JJ1 level/tileset/sprite parsing
    sprites.py              Sprite frame decoding
tests/                      Lightweight regression tests
tools/                      Developer helper scripts
game_data/                  Local DOS game files, ignored by git
openjazz/                   Optional local reference checkout, ignored by git
```

## Requirements

- Python 3.10 or newer
- Pillow
- Tkinter, normally bundled with desktop Python on Windows

Install runtime dependencies:

```bash
python -m pip install -r requirements.txt
```

For development checks:

```bash
python -m pip install -r requirements-dev.txt
```

## Game Data

Jazzed expects local game assets in:

```text
game_data/
```

At minimum, use files from a legally owned DOS Jazz Jackrabbit 1 installation, such as:

- `LEVEL*.*`
- `BLOCKS.*`
- `SPRITES.*`
- `MAINCHAR.000`
- music and resource files referenced by the original levels

`game_data/` is ignored by git and should not be committed.

## Run

Default local workflow:

```bash
python jazz1_dos_level_editor.py
```

This opens `game_data/` by default.

You can also point the editor at another DOS game directory:

```bash
python jazz1_dos_level_editor.py D:\Games\DOS\JAZZ
```

## Development Checks

Run all lightweight checks:

```bash
python tools/check_project.py
```

Run tests directly:

```bash
python -m unittest discover -s tests
```

Compile-check all Python files:

```bash
python -m compileall jazz1_dos_level_editor.py jazzed_editor tests tools
```

The tests intentionally avoid requiring `game_data/`, so they can run in a clean public checkout.

## Notes For Contributors

- Keep raw DOS file parsing in `jazzed_editor/raw/`.
- Keep Tk widgets, canvas items, editor state, and dialogs in `jazzed_editor/gui.py` or future GUI-focused modules.
- Do not import Tkinter from the raw data layer.
- Do not commit local `game_data/`, `openjazz/`, caches, or generated bytecode.
- Prefer adding small regression tests for binary helpers and data model behavior whenever moving parser code.

See [Development](docs/development.md) and [Architecture](docs/architecture.md) for more detail.
