# Game Data

Jazzed needs original DOS Jazz Jackrabbit 1 assets to run, but those files are not part of this repository.

## Local Folder

By default, Jazzed opens:

```text
game_data/
```

This folder is ignored by git except for `game_data/README.md`.

## Expected Files

Useful files include:

- `LEVEL*.*`: original level files
- `BLOCKS.*`: tilesets and palettes
- `SPRITES.*`: world/episode sprite assets
- `MAINCHAR.000`: shared character sprites
- music/resource files referenced by levels

Different Jazz releases may have different exact file sets.

## Public Repository Rules

Do not commit:

- original game data
- copied commercial assets
- local OpenJazz checkouts
- generated bytecode or caches

The `.gitignore` is intentionally set up for this:

```text
game_data/*
!game_data/README.md
openjazz/
OpenJazz/
```

## Working With Test Data

Current tests avoid requiring real `game_data/`. If future tests need binary fixtures, prefer tiny synthetic files that are generated in the test or clearly safe to redistribute.

Do not add real JJ1 files as test fixtures.
